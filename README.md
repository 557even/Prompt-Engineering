# Prompt Engineering Toolkit

This repository collects prompt templates and frameworks for working with large language models such as ChatGPT or the OpenAI Playground.

## Getting Started

1. Browse the JSON or markdown files in this repository.
2. Copy the desired content into the **System** message of your conversation or into the Playground interface.

![Prompt usage screenshot](https://github.com/rjslvn/Prompt-Engineering/assets/8602178/cd3406fe-d963-4627-970b-94b39cd12339)
