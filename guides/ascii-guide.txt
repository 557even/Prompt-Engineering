================================================================================
                            PRINTABLE CHARACTERS (0x20-0x7E)
                            ================================

SPACE CHARACTER (0x20)
├── ASCII Code: 32 decimal, 0x20 hexadecimal, 00100000 binary
├── Description: Non-printing space character
├── Keyboard: Space bar
└── Usage: Word separation, formatting

UPPERCASE ALPHABET (0x41-0x5A)
├── Range: A (0x41) through Z (0x5A)
├── Pattern: Sequential, 26 letters
├── Gap from lowercase: 0x20 (32 decimal)
└── Keyboard: Shift + letter key

LOWERCASE ALPHABET (0x61-0x7A)
├── Range: a (0x61) through z (0x7A)
├── Pattern: Sequential, 26 letters
├── Offset from uppercase: +0x20
└── Keyboard: Letter key (unshifted)

NUMERALS (0x30-0x39)
├── Range: 0 (0x30) through 9 (0x39)
├── Pattern: Sequential, 10 digits
├── Binary pattern: 0011xxxx (BCD-compatible)
└── Keyboard: Number row (unshifted)

SPECIAL CHARACTERS ANALYSIS
───────────────────────────

DETAILED ANALYSIS: "I l L" SEQUENCE (0x49 0x6C 0x4C)
─────────────────────────────────────────────────────

CHARACTER 1: UPPERCASE I (0x49)
├── Decimal: 73
├── Hexadecimal: 0x49
├── Binary: 01001001
├── EBCDIC: 0xC9
├── Baudot (ITA2): 00110 (FIGURES + 8)
├── Keyboard: Shift + I
├── Font Characteristics:
│   ├── Monospace: Single vertical bar (│)
│   ├── Serif: Includes top/bottom serifs
│   ├── Sans-serif: Pure vertical stroke
│   └── Terminal: 8x16 pixel bitmap
└── Confusion Factors:
    ├── Identical to lowercase L in many terminal fonts
    ├── Similar to digit 1 (0x31)
    └── Common source of programming errors

CHARACTER 2: LOWERCASE L (0x6C)
├── Decimal: 108
├── Hexadecimal: 0x6C
├── Binary: 01101100
├── EBCDIC: 0x93
├── Baudot (ITA2): 10110 (LETTERS + L)
├── Keyboard: L key (unshifted)
├── Font Characteristics:
│   ├── Monospace: Single vertical bar (│)
│   ├── Typographic: Often includes slight curve or tail
│   ├── Height: Typically ascender height
│   └── Terminal: Usually identical to uppercase I
└── Confusion Factors:
    ├── 90% visual similarity to uppercase I
    ├── Similar to digit 1 (0x31)
    └── Historic source of data entry errors

CHARACTER 3: UPPERCASE L (0x4C)
├── Decimal: 76
├── Hexadecimal: 0x4C
├── Binary: 01001100
├── EBCDIC: 0xD3
├── Baudot (ITA2): 10110 (LETTERS + L) - same as lowercase
├── Keyboard: Shift + L
├── Font Characteristics:
│   ├── Monospace: Vertical bar with horizontal base (┌─)
│   ├── Typographic: Distinct horizontal serif/foot
│   ├── Width: Typically wider than I/l
│   └── Terminal: Usually distinguishable
└── Usage Notes:
    ├── Roman numeral: 50
    ├── SI unit: Liter (L)
    └── Less confusing due to distinctive shape

TECHNICAL CONSTRAINTS

• 7-bit character set (128 positions)
• Teletype compatibility requirements

================================================================================
                            COMMUNICATION PROTOCOLS
                            =======================

SERIAL TRANSMISSION PARAMETERS
──────────────────────────────
Baud Rates: 110, 300, 1200, 2400, 4800, 9600 baud
Data Bits: 7 (ASCII) or 8 (extended)
Stop Bits: 1, 1.5, or 2
Parity: None, Odd, Even, Mark, Space
Flow Control: XON/XOFF (0x11/0x13) or RTS/CTS

ESCAPE SEQUENCES (VT-100)
─────────────────────────
CSI Sequences: ESC [ parameters command
Example: ESC [ 2 J  (Clear screen)
Example: ESC [ 1 ; 5 H (Move cursor)
