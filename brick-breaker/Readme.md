# Brick Breaker (Vanilla JS + Canvas)

## Run
- Option A: Open `index.html` directly.
- Option B (recommended): Use a local server (VS Code Live Server).

## Controls
- Move paddle: **A/D** or **Left/Right**
- Launch ball: **Space** or **Enter**
- Pause/Resume: **P** or **Esc**
- Mouse/Touch: move horizontally to control paddle

## Notes
- Includes levels, lives, scoring, and a simple “sticky” launch (ball starts on paddle).
