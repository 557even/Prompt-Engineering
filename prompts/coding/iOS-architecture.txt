 • Boxes = logical components / subsystems.

Key Interaction Paths (relevant to security testing):
  1. App → UIKit/CoreGraphics → ImageIO → kernel (handle_mm_fault)  
  2. App ↔ launchd ↔ userfaultfd (syscall/IOCTL) → kernel fault handler  
  3. App ↔ AirDropd ↔ Wi‑Fi‑Direct (network stack) → kernel Wi‑Fi driver  
  4. App ↔ AudioQueue (CoreAudio) → kernel audio driver → DMA buffers  
  5. App ↔ XPC (e.g., securityd, locationd) → XPC service → kernel checks
