# Prompt Engineering Toolkit

This repository collects prompt templates and how-to guides for working with large language models such as ChatGPT.

## Folder Structure

- **prompts/** – JSON prompt templates organized by category
  - **business/**
  - **coding/**
  - **creativity/**
  - **general/**
- **guides/** – markdown documentation
- **automation/** – configuration files
